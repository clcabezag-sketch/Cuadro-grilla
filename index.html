01 — Puntos del terreno

Vért.Este (X)Norte (Y)
Arrastra aquí KML, KMZ, Excel o DXF, o toca para seleccionar
Formatos admitidos: KML/KMZ, Excel (.xlsx/.xls), CSV y CAD en formato DXF (.dxf). Excel debe contener columnas de Este/Norte (o X/Y); se detectan automáticamente las dos primeras columnas numéricas si no se encuentran encabezados reconocibles. En DXF se leen polilíneas cerradas y vértices de POLYLINE/LWPOLYLINE. Los archivos DWG no se pueden interpretar directamente de forma fiable en un HTML local; para ellos usa DXF.

02 — Línea de conversión (opcional)

Calcular el otro datum a partir de un punto de control conocido en ambos sistemas
Se calcula un desplazamiento fijo (ΔE, ΔN) entre ambos datums a partir de este punto y se aplica a todos los vértices. Es una transformación local aproximada, válida solo dentro de la misma zona de trabajo — verifica siempre con el conversor oficial del IGN antes de presentar el plano ante Registros Públicos.
